# AI Resume Analyzer

This project is a lightweight MVP for an AI Resume Analyzer built with:

- Java + Spring Boot backend
- React frontend
- MySQL-ready schema and structured analysis pipeline

## Project structure

- `backend` - Spring Boot API
- `frontend` - React app

## Run backend

```bash
cd backend
export JAVA_HOME="/path/to/jdk-23"
../tools/apache-maven-3.9.9/bin/mvn.cmd spring-boot:run
```

## Run frontend

```bash
cd frontend
npm install
npm run dev
```

## Default ports

- Backend: http://localhost:8080
- Frontend: http://localhost:5173
